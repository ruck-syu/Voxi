What Voxi understands

Say any of these, or something close. Words like “please”, “the”, and “all” are ignored, and dictated numbers like “thirty” work.

  • Move and copy
  • Rename
  • Folders and sorting
  • Images
  • PDFs
  • Zip and unzip
  • Clean up
  • Find, without changing anything
  • Undo and history
  • Filters
  • Shortcuts

Move and copy

  • move report.pdf to DocumentsMoves one file. If Documents already has a report.pdf, the new one becomes report 2.pdf.
  • move all PDFs from Downloads to DocumentsMoves every matching file.
  • move files larger than 100 MB from Downloads to ExternalSize filters work with any set of files.
  • copy all images from Pictures to BackupCopies, leaving the originals in place.

Rename

  • rename report.pdf to Q3-report.pdfRenames one file, keeping its extension if you leave it off.
  • add prefix Invoice- to files named bill in DownloadsAdds text to the start of each name.
  • add date prefix to files in ScreenshotsPuts the file's date first, like 2026-10-28 shot.png.
  • replace spaces with dashes in files in DownloadsSwaps text in names; also “remove spaces from names in…”.
  • number images in Trip as trip-001Renames in order: trip-001, trip-002, and so on.
  • lowercase file names in DownloadsMakes every name lowercase.

Folders and sorting

  • create folders 2026, 2027 in DocumentsMakes one or several folders.
  • sort Downloads by typeMoves files into Images, PDFs, Videos, Documents, Archives, Installers, and Audio.
  • sort Screenshots by monthMoves files into folders like 2026-10.

Images

  • convert photo.heic to pngWrites a PNG copy; also jpg and heic.
  • resize all images in Trip to 1600 pixels wideShrinks anything wider. Undo restores the originals.

PDFs

  • merge all PDFs in Downloads into combined.pdfCombines PDFs in name order.
  • split report.pdf into pagesOne PDF per page, in a new folder.
  • extract pages 2 to 5 from report.pdf into excerpt.pdfCopies a page range into a new PDF.
  • make a PDF from images in Scans named receiptsTurns images into a single PDF.

Zip and unzip

  • zip Project into Project.zipCompresses a file or folder.
  • unzip archive.zip into Downloads/archiveExtracts into a new folder, never over existing files.

Clean up

  • clean up Downloads older than 90 daysMoves old files to the Trash. Clean-up always needs a filter.
  • delete screenshots older than 30 days“Delete” means the Trash too. Nothing is erased.
  • move installers from Downloads to TrashInstallers are .dmg and .pkg files.

Find, without changing anything

  • list files in Downloads larger than 500 MBShows matches, biggest first.
  • count PDFs in DocumentsCounts, including subfolders.
  • show size of DownloadsTotal size and the largest items.
  • list duplicate files in DownloadsSame name and size, like report.pdf and report (1).pdf.
  • open Downloads in FinderOpens a folder, or shows a file in Finder.

Undo and history

  • undo lastReverses the newest change, after its own preview.
  • show recent actionsLists what Voxi has done, newest first.

Filters

  • screenshots, images, PDFs, videos, documents, archives, installers, audioFile types. Any extension works too, like “HEIC” or “mov files”.
  • from today, from yesterday, from the last 7 daysRecent files.
  • older than 90 days, older than 1 yearOld files; weeks and months work too.
  • in August, from March 2025A calendar month. Without a year, the most recent one.
  • larger than 100 MB, smaller than 2 GBBy size.
  • named invoice, containing draftBy name.

Shortcuts

  • run my usualsSave a phrase and a list of commands in Settings. Saying it runs them all, as one preview with one undo.
