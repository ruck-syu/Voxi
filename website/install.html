Install Voxi

About two minutes, once. Voxi works on macOS 12 or later, on Apple silicon and Intel Macs.

  1. Download the app

    Get the latest Voxi .dmg, open it, and drag Voxi to Applications.

  2. Open it the first time

    Voxi isn't notarized by Apple yet, so macOS blocks the first launch. On macOS 15 or later, open System Settings, then Privacy & Security, scroll down, and click Open Anyway next to Voxi. On macOS 14 or earlier, right-click Voxi in Applications and choose Open. macOS remembers this, so you only do it once.

  3. Allow folder access

    Voxi opens a welcome page. Click Allow access and approve each folder macOS asks about, so commands never stop to ask later. Voxi only touches Desktop, Downloads, Documents, Pictures, and folders you add in Settings.

  4. Find the face in your menu bar

    Voxi has no Dock icon. Click its face in the menu bar, or press ⌃⌥Space anywhere. You can change the shortcut in Settings.

  5. Talk to it, if you like

    Optional. Voxi has no microphone access of its own; use a dictation app such as Hex or Wispr Flow. Open Voxi, dictate into its box, and press Enter to see the preview.

Prefer Homebrew?

Run this in Terminal instead of step 1. You may still need step 2 to allow the first launch.

brew install --cask ruck-syu/tap/voxi

Updates: open Settings and click Check for updates. Voxi downloads the newest release, checks its signature, and restarts.

Removing Voxi: quit it from the menu bar, then drag it from Applications to the Trash.

Voxi is open source on GitHub.
