Install Voxi

About two minutes, once. Voxi works on macOS 12 or later, on Apple silicon and Intel Macs.

  1. Download the app

    Get the latest Voxi .dmg, open it, and drag Voxi to Applications.

  2. Open it the first time

    Voxi isn't notarized by Apple yet, so macOS blocks the first launch. On macOS 15 or later, open System Settings, then Privacy & Security, scroll down, and click Open Anyway next to Voxi. On macOS 14 or earlier, right-click Voxi in Applications and choose Open. macOS remembers this, so you only do it once.

  3. Find it in the menu bar

    Voxi has no Dock icon. Click its folder icon in the menu bar, or press ⌃⌥Space anywhere. You can change the shortcut in Settings.

  4. Allow folder access

    Voxi opens a welcome page. Click Allow access and approve each folder macOS asks about, so commands never stop to ask later. Voxi never touches anything outside these folders unless you add more in Settings.

  5. Dictate with Wispr Flow

    Optional. With Wispr Flow installed, press Voxi's shortcut, then hold Fn and speak. Your words land in Voxi's box; press Enter to see the preview.

Updates: open Voxi's Settings and click Check for updates. Voxi downloads the newest release, checks its signature, and restarts.

Removing Voxi: quit it from the menu bar icon, then drag it from Applications to the Trash.

Voxi is open source on GitHub. Built for No Hands: The Wispr Challenge by WeMakeDevs.
